# 내보낼 기준 (실험 전에 정함, 2026-11-09)

이 문서는 **고치기 전 기준 점수를 재기 전에** 커밋한다. 한 번에 한 가지만 바꾸고, 아래 기준을 넘을 때만 다음 차수로 간다.
데이터셋: `data/eval/replay_1109.jsonl`(요청 읽기→자료 찾기→쓰기→수치 확인 끝까지, 실제 LLM, 항목마다 2번),
`data/eval/find_sources.jsonl`(자료 찾기만, 코드). 채점은 모두 코드.

## 모든 차수 공통
- 정상 항목(`kind=normal`)은 **하나도 떨어지지 않는다**(기준 점수에서 통과하던 것이 실패로 바뀌면 내보내지 않음)
- 이번에 고치지 않는 문제 유형의 통과 수가 **기준 점수보다 줄지 않는다**
- `pytest -q` 전부 통과(PR CI)
- 지연 시간 중앙값이 기준 점수 대비 **+20% 이내**(replay 실행 기록의 트레이스 지연)

## 1차 ① 자료 못 고름 (처음 어긋난 단계: find-sources)
- replay `자료못고름` 문제 항목 **8번 중 7번 이상** 통과(4항목 × 2번)
- find_sources.jsonl 의 자료 찾기 문제 항목(F01, F10, F11, F12) **4개 중 4개**, 정상 항목 6개 유지

## 2차 ③ 두 해 답의 연도 표시 빠짐 (처음 어긋난 단계: write)
- replay `연도표시` 문제 항목 **90% 이상** 통과(연도 표시 채점 `years_labeled`)
- 수치 확인(number-guard) 통과율이 기준 점수보다 떨어지지 않는다

## 3차 ② 조건 물음에 기준 미적용 (처음 어긋난 단계: read-request / write)
- replay `기준적용` 문제 항목 **80% 이상**, 그리고 두 번 모두 통과한 항목이 4개 이상
- 일반 물음·쓰기 정상 항목의 모드가 바뀌지 않는다(정상 항목 유지로 확인)

## 배포 뒤 확인 (차수마다)

- Langfuse 트레이스를 `version`(Cloud Run 리비전)으로 나눠 같은 현상 횟수, 지연 시간, 비용을 비교한다
- 나아지지 않으면 그 결과와 이유를 그대로 REPORT.md 에 남긴다
