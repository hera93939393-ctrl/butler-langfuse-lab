## 3. 하나 고르기: 지금 배포판으로 다시 세기
기록은 11/02판(00006)에서 나왔다. 11/03에 A를 고친 판(00008)이 배포돼 있었으므로, 후보마다 **기록 속 실패를 같은 입력으로 지금 판에서 다시 돌렸다**(`scripts/replay_logs.py`, 실제 LLM, 항목마다 2번).

| 후보 | 지금 판 통과 |
|---|---|
| D 꼬리 "찾지 못함" | 10/10 (이미 해결) |
| F 합계 지어냄 | 4/4 (이미 해결) |
| B 기준 미적용 | 7/10 |

**E를 골랐다.** 지금 판에서 완전히 실패하는 유일한 유형이고, 신고가 있었고, 앞 단계가 틀리면 뒤 단계(쓰기)가 아무리 좋아도 "찾지 못함"이 나온다. 코드 규칙 단계라 결과가 흔들리지 않고 코드로 채점할 수 있다.

원인(트레이스 `find-sources` 출력으로 확인):
- **두 해 비교**: "2024년과 2025년 사업성과 비교해줘" → 상위 5줄을 2024 줄이 다 차지해 2025가 잘림(트레이스 25, 신고 "2024년과 2025년 사업성과가 내용에 들어있는데 찾지 못한다고 함")
- **어미·조사**: "누구에게 보고해야 하지?" → 낱말이 `누구에게·보고해야·하지`로 읽혀 자료의 "보고"와 하나도 안 맞음(트레이스 20)

## 5. 고친 것 (`app/steps.py`)
1. 요청 연도가 둘 이상이면 **연도마다** 위에서 5줄씩, 연도 없는 줄(규정)도 5줄까지 고른다. 점수가 같으면 자료 순서라 두 해의 같은 항목이 짝지어진다.

## 8. 확인하면서 새로 찾은 것 (다음 후보)
1. **트레이스 절반 누락** — 새 대화 10턴 중 5턴의 트레이스가 Langfuse에 들어오지 않았다(반응 점수는 들어옴, 서버 접속 기록엔 10개 모두 200). Cloud Run은 요청 밖에서 CPU를 거의 멈추는데 SDK가 모아 두었다가 보내는 방식이었다. → 요청이 끝나면 바로 보내도록(`tracing.flush()`) 고쳐 00010으로 배포했고, 그 뒤 새 대화는 바로 들어왔다. 빠진 5턴은 되살리지 못했다(화면 캡처로만 남음).
2. **고르지 않은 자료 때문에 "찾지 못함"** — "누구한테 보고해야 돼?"를 전결규정을 고르지 않고 보내면 "찾지 못함" + 신고 "전결규정에 있는데 찾지 못함". 11/02 기록 38번도 같은 꼴. → 고르지 않은 자료에 맞는 줄이 있으면 알려 주기.
3. **두 해 답에 연도 표시가 빠짐** — 자료는 두 해를 다 골랐는데, 답이 "□ 2024년 …" 제목 하나 아래 2025 줄을 연도 없이 이어 씀(새 비교 4개 중 4개). 쓰기 지시문에 "연도마다 제목을 나눈다"를 넣고 데이터셋에 연도 표시 채점을 더할 것.
4. **표 요청 미지원** — "표처럼 정리해줘"에 표가 없음(신고).
